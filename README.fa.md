# CSP Gamepad — کنترل CLIP STUDIO PAINT با دستهٔ بازی

**دستهٔ بازی خودت را به یک کنترلر قابل‌تنظیم برای CLIP STUDIO PAINT تبدیل کن.**

CSP Gamepad یک برنامهٔ جانبی برای ویندوز است که دکمه‌ها، تریگرها و استیک‌های دستهٔ بازی را به میانبرهای صفحه‌کلید و عملکردهای ماوس متصل می‌کند. این برنامه افزونهٔ رسمی CLIP STUDIO PAINT نیست.

## تصویر محیط برنامه

تصویر نهایی محیط برنامه را سازنده به مخزن اضافه خواهد کرد.

## امکانات

- نمایش زندهٔ وضعیت دکمه‌ها، استیک‌ها و تریگرها.
- تنظیم اتصال‌ها با کلیک روی تصویر دسته.
- اتصال به میانبر صفحه‌کلید، دکمهٔ ماوس، چرخ ماوس، ماکرو، تعویض پروفایل و توقف برنامه.
- حالت‌های دکمه: `tap`، `hold`، `toggle` و `repeat`.
- ترکیب‌هایی مانند `LB+A`.
- حالت‌های استیک: `mouse`، `drag`، `keys` و `wheel`.
- تنظیم Dead Zone، حساسیت، منحنی، سرعت و معکوس‌کردن محورها.
- ساخت، تکثیر، تغییر نام، واردکردن و خروجی‌گرفتن از پروفایل‌های JSON.
- آزادکردن ورودی‌های نگه‌داشته‌شده هنگام قطع دسته یا از دست رفتن فوکوس.

## پیش‌نیازها

- ویندوز ۱۰ یا جدیدتر.
- Python نسخهٔ 3.10 یا جدیدتر.
- Tkinter (در نصب‌کنندهٔ استاندارد Python وجود دارد).
- برای بک‌اند داخلی Xbox، دستهٔ سازگار با XInput.

برای دسته‌های PlayStation، Switch و بسیاری از دسته‌های عمومی:

```bash
python -m pip install pygame
```

## نصب

1. مخزن را دانلود و از حالت فشرده خارج کن.
2. Python نسخهٔ 3.10 یا جدیدتر را نصب و گزینهٔ **Add Python to PATH** را فعال کن.
3. فایل `run_gui.bat` را اجرا کن یا دستور زیر را در پوشهٔ پروژه بزن:

   ```bash
   python -m csp_gamepad
   ```

4. دسته را وصل و CLIP STUDIO PAINT را اجرا کن.
5. پنجرهٔ CSP را فعال نگه دار. به‌صورت پیش‌فرض ورودی‌ها فقط هنگام فعال‌بودن پنجرهٔ CSP ارسال می‌شوند.

اگر CSP با دسترسی Administrator اجرا می‌شود، CSP Gamepad را هم با همان سطح دسترسی اجرا کن.

## تنظیمات

- در تب **Buttons** اتصال‌ها را اضافه، ویرایش یا حذف کن و با **Listen** دکمه‌ها را ثبت کن.
- با **Capture keyboard key** میانبر صفحه‌کلید را دریافت کن.
- در تب **Sticks** رفتار استیک‌ها و حساسیت آن‌ها را تنظیم کن.
- پیش از تغییرات مهم، با گزینهٔ Duplicate از پروفایل یک کپی بساز.
- پروفایل‌ها در مسیر `%APPDATA%\CspGamepad` ذخیره می‌شوند.

میانبرهای پیش‌فرض را در مسیر **File → Shortcut Settings** در نسخهٔ CSP خودت بررسی کن.

## گزینه‌های خط فرمان

```bash
python -m csp_gamepad --headless
python -m csp_gamepad --list-controllers
python -m csp_gamepad --list-profiles
python -m csp_gamepad --profile "Default (Painting)"
python -m csp_gamepad --self-test
```

## تست‌ها

برای اجرای تست‌ها:

```bash
python -m unittest discover -s tests -v
```

طبق گزارش توسعه، ۳۰ تست خودکار در محیط توسعه موفق بوده‌اند. این تست‌ها جایگزین آزمایش کامل روی ویندوز واقعی، با دستهٔ فیزیکی و CLIP STUDIO PAINT نیستند.

## محدودیت‌های شناخته‌شده

- برنامه فقط برای ویندوز طراحی شده است.
- ورودی واقعی XInput، ارسال با Windows `SendInput`، ظاهر واقعی Tkinter و تعامل زنده با CSP هنوز به آزمایش کامل روی ویندوز نیاز دارند.
- میانبرهای پیش‌فرض ممکن است با نسخه یا تنظیمات شخصی CSP متفاوت باشند.
- حالت‌های `mouse` و `drag` نشانگر ماوس را حرکت می‌دهند و ممکن است با قلم نوری تداخل داشته باشند؛ حالت‌های `keys` یا `wheel` را هم در نظر بگیر.
- ترکیب برای استیک‌ها پشتیبانی نمی‌شود و ترکیب دکمه‌ها حداکثر سه دکمه دارد.
- پشتیبانی دسته‌های غیر XInput از طریق pygame باید روی ویندوز آزمایش شود.
